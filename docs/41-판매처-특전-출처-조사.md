# 판매처 특전은 어디서 오는가 — 경로 4개 반증 기록

> 조사 2026-08-28 · 코드 레인.
> **결론: 자동 수집 경로가 없다.** 아래 넷을 전부 실측으로 반증했다.
> 다시 시도하기 전에 이 문서를 읽어라 — 각 경로가 왜 안 되는지 증거와 함께 적혀 있다.

---

## 0. 무엇을 풀려고 했나

특전 커버리지가 **81건에서 안 움직인다.** 하루에 세 번 쟀는데 비율만 출렁였다.

| 시점 | 전체 행 | 특전 | 비율 |
|---|---:|---:|---:|
| 조사 당시 | 562 | **81** | 14.4% |
| 뮤직플랜트 연결 불가 | 498 | **81** | 16.3% |
| 뮤직플랜트 복귀 | 567 | **81** | 14.3% |

**분자가 한 번도 안 움직였다.** 비율은 뮤직플랜트가 분모에 있느냐로만 변했다.
파서를 고쳐서 오를 수 있는 수치가 아니라는 뜻이다.

비어 있는 곳은 넷이다.

| 판매처 | 행 | 특전 | 비율 |
|---|---:|---:|---:|
| 위드뮤 | 76 | 0 | 0% |

## 1. 판매처 상품 상세 — 없다

넷 다 상품 페이지를 직접 받아 확인했다.

| 판매처 | 응답 | 텍스트 | "특전" |
|---|---:|---:|---:|
| 사운드웨이브 | 135KB | — | **0건** |
| 위드뮤 | 142KB(렌더) | 14,248자 | **0건** |
| 애플뮤직 | 126KB | **2,990자** | **0건** |
| 뮤직플랜트 | 37KB | 6,788자 | **0건** |

위드뮤에 "증정·혜택"이 6건 잡히길래 봤더니 전부 교환·반품 안내 보일러플레이트였다.

**OCR도 답이 아니다.** 애플뮤직은 텍스트가 2,990자뿐이라 "설명이 이미지겠거니" 싶었는데,
실제로 열어보니 앨범 제품컷이었다.

- 위드뮤 `1000017048_detail_031.jpg` → `NEMO Ver.` 상자 두 개 사진
- 애플뮤직 `009001035386.jpg` → 엔하이픈 앨범 7종 봉투 사진, 페이지 전체에 이미지가 **2장뿐**

**특전 안내 자체가 없다. 글자로도 이미지로도.**

---

## 2. 판매처 이벤트 게시판 — 거의 비어 있다

둘 다 EVENT 게시판이 있다.

- 사운드웨이브 `/board/gallery/list.html?board_no=8&category_no=1` → "특전" **0건**
- 뮤직플랜트 `/board?db=gallery_1&cate=17` → "특전" **1건** (SUPER JUNIOR-83z 1건뿐)

X 계정은 하루 3~5건 올리는데 게시판은 두 달에 몇 건이다. 같은 정보원이 아니다.

---

## 3. 특전은 X 공식 계정에 있다 — 출처는 찾았다

로그인한 크롬으로 확인했다. 넷 다 계정이 있고, 구조가 규칙적이다.

| 판매처 | 핸들 | 형식 |
|---|---|---|
| 뮤직플랜트 | `@musicplant_kr` | `[PRE-ORDER GIFT]` · `[FANSIGN EVENT]` |
| 사운드웨이브 | `@soundwave_korea` | `SPECIAL GIFT EVENT` · `LUCKY DRAW EVENT` |
| Ktown4u | `@Ktown4u_kr` | — |
| 위드뮤 | `@Withmuu_twt` | `[ 응모 기간 ]` · `[ 응모자 특전 ]` · `[ 당첨자 특전 ]` |

실제 게시물 (뮤직플랜트, 8/26):

> `[PRE-ORDER GIFT]` #아이들 #idle #소연 #SOYEON #끝내주는인생
> 집 ver. 구매 시 뮤직플랜트 독점 미공개 셀피 포토카드 A 3종 중 랜덤 1종 증정
> 섬 ver. 구매 시 … B 3종 중 랜덤 1종 증정

**우리 사이트는 소연 앨범을 "판매처 2곳"으로 표시한다.** 뮤직플랜트도 팔고 특전도 주는데 빠져 있다.

### 덤으로 나온 것 — 팬사인회를 메이크스타만 여는 게 아니다

뮤직플랜트, 8/25 · 조회 5.3만:

> `[FANSIGN EVENT]` #태민 #TAEMIN #PHASE1_SoftViolence
> 이벤트: 2026년 9월 5일(토) **[대면/30명] 18:30 ~ [영통/20명]** · 응모기간 ~8/28 23:59

위드뮤도 같은 걸 한다(이브 `[NAIL]` 팬사인회, 8/29 마감).
**사이트는 "이 이벤트들은 메이크스타에서 그 앨범을 사야 응모됩니다"라고 단정한다. 사실이 아니다.**
→ 이건 특전과 별개로 고쳐야 할 문구다(프론트 레인).

## 4. 그런데 그 X를 자동으로 못 읽는다 — 여기서 막혔다

### 4-A. syndication 임베드 — 최신이 아니다

`https://syndication.twitter.com/srv/timeline-profile/screen-name/<핸들>`
인증 없이 200에 700KB, `__NEXT_DATA__`에 JSON 100건. **되는 것처럼 보인다.**

러너에서도 4계정 전부 200이 떴고 "특전 90건"이 잡혔다. 거기서 성공으로 판정했는데 틀렸다.

받아서 **날짜를 세어보니** 이렇다.

| 계정 | 건수 | 최신 | 2026년 글 |
|---|---:|---|---:|
| musicplant_kr | 100 | 2025-10-30 | **0** |
| soundwave_korea | 99 | 2025-09-29 | **0** |
| Withmuu_twt | 100 | 2025-10-22 | **0** |
| Ktown4u_kr | 98 | 2026-08-27 | **1** |

시간순 최신이 아니라 **오래된 표본**을 준다(musicplant는 2024년 글이 37건으로 제일 많다).
예판 특전 공지는 발매 직전에 뜨므로 이걸로는 못 잡는다.

### 4-B. 로그아웃 x.com + Playwright — 러너에서 403

로컬에서는 된다. 로그아웃 상태로도 최근 글(17시간 전)까지 보인다.
**단 6건이 상한**이고 스크롤하면 로그인 유도가 뜬다.

러너에서는 안 된다.

```
musicplant_kr → HTTP 403
   article 대기 실패 (25초)
   title= · body=0 · article=0
Withmuu_twt   → HTTP 403
```

로그인 벽이 아니라 **403**이다. x.com이 GitHub Actions IP를 차단한다.

## 5. 남은 것

**X API v2** 하나다. 종량제($0.005/read)라 4계정 × 하루 2회면 월 $6 수준이지만,
개발자 계정 개설과 키 관리가 붙는다.

**권고 — 지금은 접는다.** 얻는 게 "판매처 4곳 특전"인데 비해 관리 부담이 크고,
6건 창이든 API든 **놓친 공지는 백필이 안 된다**(과거 트윗 검색은 더 비싼 티어다).
그 구멍은 이미 만들어 둔 **제보 기능**이 메우는 구조가 맞다.

**그리고 게이트 지표를 바꿔야 한다.** "특전 칸 채움률"은 분모의 절반이
원리적으로 채울 수 없는 칸이라 영영 안 오른다. 빌드가 이미 찍고 있는
`특전 2곳 이상 비교 가능: 16개 중 8개`가 맞는 지표다.

기록으로 남긴다. [`CLAUDE.md`](../CLAUDE.md)의 절대 규칙과 같은 패턴에 세 번 걸렸다.

| 규칙 | 어긴 것 |
|---|---|
| ① 대리 지표로 내용을 판단하지 마라 | syndication이 200·749KB·"특전 90건"이라 성공으로 판정. 날짜를 안 봤다 |
| ② 못 찾은 것을 "없다"로 단정하지 마라 | 위드뮤 핸들을 `withmuu_official`로 한 번 찍어보고 "계정 없음"이라 보고. 실제로는 `@Withmuu_twt` |
| ② 같은 규칙 | 상품 상세만 보고 "사운드웨이브는 특전을 안 준다"고 결론. X에는 하루 3건씩 올린다 |
| ③ 입력을 바꿔도 안 변하는 응답은 신호가 아니다 | syndication은 언제 불러도 같은 옛 데이터를 준다. 두 번 불러 비교했으면 바로 걸렸다 |

**공통점은 하나다 — 응답이 왔다는 것과 그 내용이 쓸 만하다는 것을 구분하지 않았다.**
